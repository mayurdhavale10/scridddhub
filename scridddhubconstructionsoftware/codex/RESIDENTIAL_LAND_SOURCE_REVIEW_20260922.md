# Residential land source review - 22 September 2026

No new listing observations or model additions were produced in this review.
Web research inspected candidate homepages and published navigation. Web-tool
results can be cached and do not demonstrate local collector accessibility.

MagicBricks remains the only source in the reviewed benchmark: 889 historical
observations, 574 source listing IDs, 364 benchmark records. NoBroker has ten
diagnostic cards (three direct, seven nearby), not integrated into the model.

The saved MagicBricks pilot dated 20 September reports:

- Thane: 30 direct cards on page 1; metadata reported 205 results and seven pages.
  The published page-2 link returned HTTP 404.
- Shahad: attempted east-facing navigation route returned HTTP 404.
- Kalyan: two direct cards on one page; no Khadakpada route discovered.

Those gaps remain open. Future technical work needs current published routes,
small sequential batches, evidence retention, and reviewed incremental yield.
Changing browsers alone does not establish that a missing route now exists.

PropertyWala's public developer API describes posting listings, user
registration/authorization, and checking listing credits. It does not establish
a bulk listing-read feed. Reeltor's Maharashtra route returned regional context;
a listing-link check was inconclusive. 1acre.in remains a geospatial feature-data
candidate rather than an established price source.
