## Decisions (and why)
- **Stations, airports, mangroves and the rest come from OpenStreetMap now; legal zoning waits.**
  These are cheap and reliable, and the nearest existing station is the strongest value driver
  in Mumbai. DP zones, CRZ, airport height limits and flood maps need official maps, which is
  the separate Planning feature.
- **Mangroves and forests go under Planning & zoning, not Watch out.** They're a legal limit
  on building, not a nuisance.
- Left out on purpose: **slums** (a sensitive, stigmatising label), and single IT offices
  (companies, not hubs).

## Problems hit and fixes
- **`docker` not found:** Docker Desktop is installed per-user
  (`%LOCALAPPDATA%\Programs\DockerDesktop`), so its CLI isn't on PATH. Started Docker Desktop
  from there; the CLI is at `...\DockerDesktop\resources\bin\docker.exe`.
- **Emulator crashed on boot** ("WHPX: Unexpected VP exit code 4", device stuck offline) when
  it started while Docker Desktop was still starting. Fixed by force-stopping it and
  cold-booting (`emulator -avd Pixel_8_Pro -scale 0.7 -no-snapshot-load`) after Docker was up.
  Booted in 33 s.
- **Emulator window off-screen again** (`Top=-1012`, the known bug in
  `docs/android-emulator-troubleshooting.md`). It was missed at first, because the adb
  screenshot looked fine. Moved it to `(100, 0)` without resizing so it fits the 864-px screen.
  Added the boot-crash section to that doc.
- **Airoli station missing:** stations there are mapped as station buildings (ways), not
  points. The query now asks for both.
- **Overpass 429/504 while testing:** the 2-minute retry pause brought the Watch out group
  back on its own after one failed fetch.
