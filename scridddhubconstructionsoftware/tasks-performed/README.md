# Tasks performed

A log of what was done in each working session: one file per session, named
`YYYY-MM-DD-short-topic.md` (the date the session started). Newest at the bottom of the index.

Why: the code and git history say *what* changed; these notes say *why*, what was decided,
what was tried and dropped, and what's left, so the next session (or a new teammate) can
pick up without re-reading everything.

## How to write one

Copy the template below into a new file at the start of a session and fill it in as you go.
Keep it factual: what was built, what was decided and why, what broke and how it was fixed,
what's still open. Don't put keys, passwords or personal details in these files. The repo is
shared.

```markdown
# <Date>: <topic>

**Goal:** what we set out to do.

## Done
- ...

## Decisions (and why)
- ...

## Problems hit and fixes
- ...

## Commits
- `<hash>` <message>

## Still open / next
- ...
```
